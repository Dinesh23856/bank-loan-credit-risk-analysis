# Data dictionary

Core customer fields: age, gender, marital_status, dependents, education, employment_type.

Financial fields: monthly_income, annual_income, monthly_debt, debt_to_income_ratio, savings, bank_balance, assets.

Credit fields: credit_history, previous_loans, previous_defaults, payment_history, credit_utilization, credit_score.

Loan fields: loan_type, requested_loan_amount, loan_term, interest_rate, collateral_value, approved_loan_amount, loan_status.

Risk target: risk_level.
